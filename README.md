# Паралельна обробка гістограм у PARCS-Python (AWS EC2)

Лабораторна робота 1 з курсу «Хмарні обчислення», КНУ імені Тараса Шевченка.
Автор: Суховерська Наталія.

Гістограма масиву з N цілих значень у діапазоні 0–255 (16 кошиків) будується за схемою
Map–Reduce у системі ПАРКС (PARCS-Python). Кожен воркер рахує локальну гістограму своїх
блоків даних, майстер сумує результати. Кластер (1 master + 4 воркери, t3.micro)
розгорнуто в Amazon EC2, регіон eu-north-1.

## Результати

| N | W = 1 | W = 2 | W = 3 | W = 4 | Прискорення на 4 воркерах |
|---|---|---|---|---|---|
| 2 млн | 2,124 с | 1,055 с | 0,770 с | 0,602 с | 3,53 |
| 10 млн | 10,506 с | 5,267 с | 3,518 с | 2,644 с | 3,97 |

Послідовна версія (N = 2 млн): 1,960 с. Повний аналіз у звіті `report/report.pdf`.

## Структура

```
solver.py            розв'язок для PARCS-Python (клас Solver, Map–Reduce)
sequential.py        послідовна версія (еталон)
inputs/              вхідні файли: "N K SEED CHUNKS"
results/             вихідні файли ПАРКС для 1–4 воркерів, summary.csv
deploy_aws.sh        створення / видалення кластера в AWS EC2
report/              звіт (report.tex, report.pdf), рисунки, plot.py
```

## Запуск

1. В AWS CloudShell: `bash deploy_aws.sh up`, через 3–4 хвилини відкрити
   `http://<публічна IP master>:8080`.
2. Add Job: Solution File = `solver.py`, Input File = `inputs/input_10m.txt`.
3. Кількість воркерів змінюється кнопками Disable / Enable на вкладці Nodes.
4. Послідовна версія: `python3 sequential.py inputs/input_10m.txt out.txt`.
5. Після тестів: `bash deploy_aws.sh down`.

Формат вхідного файлу: `N K SEED CHUNKS`, наприклад `10000000 16 42 24`. CHUNKS має
ділитися на кількість воркерів; однакові SEED і CHUNKS дають однакові дані.
